# PilotMeter 0.1.0-preview.19

修复已开启 PET 动效却完全看不到动作的问题，并加强待机和通知动作。

## 更新内容

- 修复 Windows 菜单动画关闭时，PET 待机和通知动作被一起禁用的问题。“宠物动画”开关现在独立控制 PET 动作，无需修改系统设置。
- 加强 10 个 PET 的摇摆、悬浮、挥爪、摆尾、叶子和翅膀动作，在默认尺寸下更容易看见。
- 更新与通知动作持续约 3 秒，随后平滑回到待机动作。右键“预览提醒动作”可以立即查看三种提醒。
- 账户页和右键菜单统一使用“宠物动画”开关；关闭后 PET 保持静止。

## 使用与升级

使用 `PilotMeter-0.1.0-preview.19-win-x64.exe`。先结束采集中的 Copilot 会话，从旧宠物或托盘菜单退出桌面程序，再执行旧版 EXE 的 `stop` 命令停止后台服务，最后启动新 EXE。账号、账本和宠物设置保留。使用自定义数据目录时，停止与启动命令需使用相同的 `--data-dir`。

仍为 Windows 10/11 x64 预览版，主窗口需要 WebView2 Evergreen Runtime。
