整理 Windows 原生界面的信息层次，并完善“添加账号”的响应、失败提示与重试恢复。

- 主窗口和登录窗口在完整创建控件后统一处理 DPI；窄窗口、短屏幕可滚动查看全部操作。
- 主界面采用灰白背景、绿色重点、带图标的侧栏和更紧凑的卡片。额度在空间充足时横向排列，窄窗口或长数字时回到纵向排列；账号和模型卡片按内容调整高度。
- 额度按“已用、总额、剩余”对齐显示。`62,000`、`2,000,000` 等原始数量直接可见，超长数字保持单行并支持横向查看。数量及上游百分比保留完整十进制精度；无法精确表示的循环百分比显示原始数量关系，不四舍五入。单位未声明时明确标注，不推断为 Credits。
- 左下角显示当前账号、连接状态和账号管理入口；保留账户页的宠物设置，并采用与界面一致的绿色图标。
- 登录按获取验证码、复制并打开 GitHub、返回等待授权三个步骤引导，支持倒计时、过期重试，以及网络失败和授权拒绝提示。进度和错误原因位于窗口上部，短窗口也能先看到当前状态。
- “添加账号”在服务离线、账号操作不可用等状态下给出具体提示；打开登录窗口失败时恢复按钮和轮询，允许重试。服务重连时，旧登录流程不会释放新登录的状态或覆盖其反馈。登录窗口限制在当前显示器可见范围内。
- 网页预算保存与刷新完成后再显示成功并恢复操作，防止紧接着按回车清除预算时丢失提交；保存期间的新输入会保留。
- 后台版本冲突时提供“重启本机服务”。操作核对实例并等待旧服务释放写锁；定时刷新不自动停止后台。
