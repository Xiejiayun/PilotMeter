Windows 主窗口改为随包编译的 HTML + Tailwind CSS 工作台，保留原生桌面 PET、独立应用窗口和单文件 EXE 入口。

- 总览、可用模型、用量记录和账户四页采用统一的冷白背景、深色文字、绿色重点、图标与间距。额度卡片优先展示关键数字，窄窗口与短屏幕可滚动，超长数字保留完整数值。
- 同一类别的“已用、总额、剩余”对齐显示。接口没有声明计量单位时，前两项显示原始数量，第三项明确为“剩余比例”；不推算剩余 Credits。`66,000` 是六万六千，`96.7%` 是比例。数量和上游百分比保留完整十进制精度，不使用 K/M 缩写或四舍五入。
- 模型支持名称搜索和状态筛选，展示当前账号实际返回的可用性、能力与倍率；本机记录按账号、UTC 月份、排序与分页查看。
- 账户页支持添加、切换、重新登录、移除，以及十个 PET 的预览和设置。切换时清除旧快照，过期响应不能覆盖新账号。PET 与主窗口共享当前账号和宠物偏好。
- 点击添加立即打开登录弹窗，按获取验证码、复制并打开 GitHub、返回等待授权三步引导。当前状态位于顶部，包含倒计时、过期、网络失败、重试与取消。授权请求响应丢失后，重新登录只恢复匹配目标账号的待授权流程。完成后不再滞留“正在读取”提示，也不会覆盖实际读取失败的原因。
- WebView2 仅允许已确认本机实例的页面与接口；宿主通信按服务代次和操作身份确认。PET 与主窗口互斥修改账号，登录等待期间仍检测服务连接，断线后可重连恢复。
- 网页预算保存与刷新完成后再显示成功并恢复操作，防止紧接着按回车清除预算时丢失提交；保存期间的新输入会保留。
- 后台版本冲突时提供“重启本机服务”。操作核对实例并等待旧服务释放写锁；定时刷新不自动停止后台。
- HTML、Tailwind 样式、脚本和宠物图片均随应用提供，无在线 CDN 依赖。另提供离线交互设计稿与 HTML 设计报告，可用 `npm run design:export` 从正式页面源码重新导出。

下载 `PilotMeter-0.1.0-preview.12-win-x64.exe` 直接运行，或使用包含同一 EXE 的 ZIP。支持 Windows 10/11 x64、.NET Framework 4.8，无需另装 Node/npm。主窗口需要 Microsoft Edge WebView2 Evergreen Runtime；缺少时会显示 Microsoft 官方安装入口和重试提示，不在用户设备上静默安装。

升级前从旧宠物右键菜单选择退出，再启动新 EXE。关闭主窗口不会退出旧桌面实例。如提示后台版本冲突，先结束采集中的 Copilot 会话，再点击“重启本机服务”。账号、账本和设置继续保存在原数据目录。
