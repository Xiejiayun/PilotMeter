# PilotMeter 0.1.0-preview.14

本次修复点击“同步”后仍可能沿用旧额度快照的问题。

- 手动同步绕过后台自动刷新的 60 秒间隔，重新请求当前账号额度；正在进行的同账号请求仍合并处理。
- 每轮同步前重新建立额度查询进程并核实账号；查询结束后释放进程，避免沿用登录或上一轮查询留下的额度缓存。
- 同步完成提示按发起同步的账号显示；切换账号不会将上一个账号的同步结果报为当前账号成功。界面明确展示 GitHub 返回的快照，不承诺实时用量。

GitHub 的用量入账和额度更新仍可能延迟。重新请求后数值未变化，不代表尚未发生消耗；本次修复不保证 GitHub 立即返回刚产生的使用量。

## 使用与升级

使用 `PilotMeter-0.1.0-preview.14-win-x64.exe`。先结束正在采集的 Copilot 会话，在旧版宠物或托盘菜单中退出桌面程序，再执行旧版 EXE 的 `stop` 命令停止后台服务，最后启动新 EXE。关闭主窗口或退出桌面界面不会停止旧服务，只替换 EXE 文件也不会更新正在运行的进程。

账户、账本和宠物设置保留在原数据目录，升级不清空数据。使用自定义数据目录时，停止和启动命令都应带上相同的 `--data-dir`。

支持 Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Evergreen；无需另装 Node/npm。
