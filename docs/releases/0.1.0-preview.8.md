Windows 桌面版新增 10 个可切换 PET 角色，并按桌面设计稿重做原生主窗口。

- 双击 EXE 显示透明桌面宠物，点击打开独立主窗口；支持拖动、托盘恢复、角色与大小设置。
- 总览明确展示当前账户的额度类别、总额、已用、剩余和同步状态；未知单位不伪装成 Credits。
- 可用模型来自当前账号的官方 Copilot CLI 目录及策略；本机用量记录独立展示，支持账号切换。
- 账户页管理 GitHub 登录、重新授权、移除及宠物偏好。关闭主窗口保留宠物。
- 提供一键本地打包与 GitHub Actions 版本标签发布流程。

下载 `PilotMeter-0.1.0-preview.8-win-x64.exe` 可直接运行；ZIP 包含同一个 EXE、使用说明与校验信息。支持 Windows 10/11 x64，需系统 .NET Framework 4.8，无需另装 Node/npm/WebView。`SHA256SUMS` 校验全部发布文件。

升级前从旧宠物菜单退出桌面界面，再用旧 EXE 执行 `stop`，之后启动新版。升级保留原数据目录中的账户、账本与设置。

本机验证通过：234 项 Node 测试、36 项 Chromium 测试、626 项原生检查、7 组 npm 安装验收、17 组实际 EXE 验收和发布文件校验。原生窗口启动与控件读取成功；12 张离屏渲染图完成布局检查。桌面自动化受系统访问错误阻挡，真实点击、拖动、托盘恢复和跨屏 DPI 尚未完成验收。

该版本仍为未签名预览版。单位、额度范围与模型状态以官方接口实际返回为准；组织共享额度与真实 `/usage` 对账需要对应主体的权限和核验，不能用本机记录代替。自动化回归与隔离 EXE 验收不等同于干净系统、多显示器和真实账单验收。
