# PilotMeter 0.1.0-preview.17

隐藏桌面工作台页面、侧栏与弹窗的纵向滚动条，保留滚轮、触控板和键盘滚动。Windows 高对比度模式沿用系统滚动条；长数值与宽表的横向滚动保持可用。

保留 preview.16 的真实额度刷新与来源时间显示。

## 验证

- 9 项相关浏览器回归通过；在 840×567、1260×850 和 760×580 视口验证滚轮、PageDown 与下方控件的键盘可达性，并检查小窗口登录弹窗和高对比度模式。
- Windows WebView2 的 53 项 DOM、样式、桥接与恢复检查通过；页面外观使用 Chromium 截图核对。
- Windows EXE、ZIP、版本清单与 SHA-256 校验通过，安装包内页面和样式与验证过的构建一致。

## 使用与升级

使用 `PilotMeter-0.1.0-preview.17-win-x64.exe`。先结束采集中的 Copilot 会话，从旧宠物或托盘菜单退出桌面程序，再执行旧版 EXE 的 `stop` 命令停止后台服务，最后启动新 EXE。账号、账本和宠物设置保留。使用自定义数据目录时，停止与启动命令需使用相同的 `--data-dir`。
