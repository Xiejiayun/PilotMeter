修复 Windows 高缩放下的文字重叠、旧后台阻止登录，以及额度数字难以阅读的问题。

- 主窗口和登录窗口在完整创建控件后统一处理 DPI；窄窗口、短屏幕可滚动查看全部操作。
- 额度按“已用、总额、剩余”对齐显示。`62,000`、`2,000,000` 等原始数量直接可见，超长数字保持单行并支持横向查看。数量及上游百分比保留完整十进制精度；无法精确表示的循环百分比显示原始数量关系，不四舍五入。单位未声明时明确标注，不推断为 Credits。
- 左下角显示当前账号、连接状态和账号管理入口；保留账户页的宠物设置，并采用与界面一致的绿色图标。
- 登录按获取验证码、复制并打开 GitHub、返回等待授权三个步骤引导，支持倒计时、过期重试，以及网络失败和授权拒绝提示。
- 后台版本冲突时提供“重启本机服务”。操作核对实例并等待旧服务释放写锁；定时刷新不自动停止后台。

下载 `PilotMeter-0.1.0-preview.10-win-x64.exe` 直接运行，或使用包含同一 EXE 的 ZIP。支持 Windows 10/11 x64、.NET Framework 4.8，无需另装 Node/npm/WebView。

升级前从旧宠物右键菜单选择退出，再启动新 EXE。关闭主窗口不会退出旧桌面实例。如提示后台版本冲突，先结束采集中的 Copilot 会话，再点击“重启本机服务”。账号、账本和设置继续保存在原数据目录。
