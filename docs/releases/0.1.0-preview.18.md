# PilotMeter 0.1.0-preview.18

桌面 PET 现在平时也会持续轻轻活动，收到更新或通知时做更明显的动作，再平滑回到待机姿态。

## 更新内容

- 10 个 PET 都有自己的待机与提醒动作，包括挥爪、摇尾巴、摆动翅膀、叶子和触须。动画图层随 EXE 离线提供。
- 用量变化、同步结果、登录状态变化，以及从主窗口启动的 Copilot 会话结束时触发提醒；相同数据的重复轮询不会反复播放。
- 右键 PET 的“预览提醒动作”可以直接试三类提醒。关闭轻动效或系统减少动画时保持静止。
- 主窗口同步时显示动画，同一账号的数字与进度条平滑变化，结束后保留原始精确数值。

## 使用与升级

使用 `PilotMeter-0.1.0-preview.18-win-x64.exe`。先结束采集中的 Copilot 会话，从旧宠物或托盘菜单退出桌面程序，再执行旧版 EXE 的 `stop` 命令停止后台服务，最后启动新 EXE。账号、账本和宠物设置保留。使用自定义数据目录时，停止与启动命令需使用相同的 `--data-dir`。

提醒来自 PilotMeter 的内部状态和已采集的用量，不读取 Copilot 的聊天内容。仍为 Windows 10/11 x64 预览版，主窗口需要 WebView2 Evergreen Runtime。
