# PilotMeter 0.1.0-preview.13

本次修复 Windows 工作台中“用量记录”和“最近会话”无法顺畅使用的问题。

- 总览和用量记录页增加“启动 Copilot 会话”。选择已登录账号及项目文件夹后，打开内置 Copilot 终端并启用本机采集，无需手动输入命令。
- 已经打开的记录列表会随自动刷新和“同步”显示新增会话，加载更多后的记录也会更新。
- 本月最近会话单独按活动时间读取，不再受记录页月份、排序和分页影响。
- 未登录、等待采集、取消启动和启动失败都有对应提示。没有上报费用的会话仍显示为待确认，不推算成零。

## 使用与升级

下载 `PilotMeter-0.1.0-preview.13-win-x64.exe` 或便携 ZIP。退出旧版桌面宠物后打开新 EXE；若提示后台版本不符，先结束正在采集的会话，再使用“重启本机服务”。原账号、账本和宠物设置保留。

登录并选择账号 → 点击“启动 Copilot 会话” → 选择项目文件夹 → 在终端中完成对话 → 返回 PilotMeter 查看记录。记录按 UTC 月份筛选，可点击“同步”立即更新。

支持 Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Evergreen。无需另装 Node/npm，缺少 WebView2 时提供官方安装入口。

## 数据范围

登录 GitHub 可以读取账号额度与模型，不能取得历史聊天明细。仅从 PilotMeter 启动并产生遥测的 Copilot CLI 会话进入本机账本；其他终端和 IDE 中的使用不自动补录。PilotMeter 只保存计量元数据，不将对话正文导入账本。

本版本仍为预览版。原始 nano AIU 与官方额度分开展示；真实多账号采集、组织共享账单及 `/usage` 对账仍未完成验证。Windows EXE 尚未进行代码签名。
