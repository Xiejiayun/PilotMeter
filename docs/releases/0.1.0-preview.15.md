# PilotMeter 0.1.0-preview.15

修复同步后的已用额度因上游百分比精度不足而偏大、与 VS Code 不一致的问题。

- 优先使用同一账号、同一查询进程中验证过的剩余额度，按总额减剩余量计算已用；优先保留 `quota_remaining` 中的小数，其次使用 `remaining`。
- 无限额度、超额用量、缺失或不一致的数据继续使用原额度接口结果。计算不会推断或转换计量单位。
- 界面说明已用数值的来源，并提示 GitHub 返回的百分比可能已经舍入，不能用于反算精确已用量。

此版本保留 preview.14 的同步缓存修复。GitHub 的用量入账仍可能延迟；不同客户端在不同时间取得的快照也可能不同。

## 使用与升级

使用 `PilotMeter-0.1.0-preview.15-win-x64.exe`。先结束采集中的 Copilot 会话，从旧宠物或托盘菜单退出桌面程序，再执行旧版 EXE 的 `stop` 命令停止后台服务，最后启动新 EXE。只替换文件不会更新正在运行的进程。

账户、账本和宠物设置保留在原数据目录。使用自定义数据目录时，停止和启动命令应带上相同的 `--data-dir`。
