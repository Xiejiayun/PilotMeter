PilotMeter · 十个桌面小伙伴

打开上一级 pets.html 查看全部角色、轻动效和小尺寸预览。
每个角色提供独立 SVG 矢量文件与 512×512 透明背景 PNG；pets-contact-sheet.png 为总览。
Windows 打包会将角色 PNG 与 animation/ 下的透明图层嵌入 EXE。
每个角色平时持续播放小幅度待机动作，有更新或通知时播放更明显的动作。
支持数据更新、收到消息、需要留意三类提醒；宠物右键“预览提醒动作”可查看。
图层来自本目录 SVG，可运行 node scripts/generate-pet-animation-layers.mjs 重新导出。
提醒在约 3 秒后平滑回到当前待机姿态；关闭“宠物动画”时显示静态原图。此开关独立于 Windows 菜单和窗口动画设置。
